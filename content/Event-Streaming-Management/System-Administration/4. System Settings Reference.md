The system admin Settings page is organized into tabs. This page documents each tab's settings and
their current, correct behavior.

# General

- **Operation Mode** — `record_only`, `lite_mode`, or `full_power`, gating how much of the pipeline
  runs platform-wide. Shown as a banner to both admins and clients.
- **File Sweep** — housekeeping for on-disk recordings once they're safely archived.

# Scaling

Minimum/maximum replica counts per background worker (clipper, uploader, etc.), for tuning
throughput against cluster capacity.

# Match Polling

Controls for how often the platform polls the *FIRST* Events APIs for schedule and result updates.

# Ingest

Settings for the RTMP ingest path, including codec/re-encode handling described under
[[Event-Streaming-Management/System-Administration/4. System Settings Reference#Clipping|Clipping]]
below and in
[[Event-Streaming-Management/Operators/6. Troubleshooting|Troubleshooting]].

# Clipping

Includes clip fade in/out settings and storage retention. Re-encoding behavior for restreamed
sources: when re-encoding is enabled, a non-H.264 source is transcoded to a matching royalty-free
encoder for its codec family, except HEVC sources, which are downconverted to H.264 rather than
re-encoded as HEVC (to avoid H.265 encoder licensing exposure). With re-encoding disabled, an
unsupported source produces a clear error naming the codec rather than a silent failure.

# Branding

Default pre-roll/post-roll video handling at the platform level (Client-level branding is set from
[[Event-Streaming-Management/Client-Administration/4. Branding|Branding]] instead).

# YouTube

- **Quota Throttle** — the platform's YouTube Data API usage is a **single system-wide daily
  quota**, not a per-Client quota. This setting controls the throttle/cost accounting against that
  shared budget; when it's near its limit, uploads across every Client can show as paused (see
  [[Event-Streaming-Management/Operators/5. Clips, Uploads and Signage#Uploads|Clips, Uploads and Signage]]).
- **Upload privacy** and **automatic token refresh** for linked channels.
- **Restream switches** — there are two independent restream on/off switches, each naming the path
  it governs: one gates the legacy manual-stream-key restream path, the other gates the Livestream
  Control Center restream path used for full YouTube broadcasts. They are not interchangeable and
  do not have to be set the same way.

# Blue Alliance

Platform-wide defaults for The Blue Alliance integration (FRC only); per-event credentials are set
from
[[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference#Blue Alliance Credentials (FRC Only)|Event Configuration Reference]].

# Signage

Platform-wide signage defaults; per-sign assignment is done from
[[Event-Streaming-Management/Operators/5. Clips, Uploads and Signage#Signage|Clips, Uploads and Signage]].

# OBS

- **Encoder profile** — the OBS output profile the plugin applies when an operator selects an
  event.
- **Plugin distribution** — whether the Download button on the client OBS Plugin page is enabled.
- **Pairing** — settings governing the plugin pairing-code flow described in
  [[Event-Streaming-Management/Client-Administration/5. OBS Plugin Devices|OBS Plugin Devices]].

# Slack

Platform-wide Slack notification defaults; workspace linking itself is done from
[[Event-Streaming-Management/Client-Administration/3. YouTube and Slack Integrations#Connecting Slack|YouTube and Slack Integrations]].

# Test Mode

Two settings, `test_mode_upload_enabled` and `test_mode_restream_enabled`, apply only to events
explicitly marked as test events — they don't correspond to a platform-wide "test mode." See
[[Event-Streaming-Management/System-Administration/7. System Admins and Test Mode|System Admins and Test Mode]] for the full test-event workflow.

# System-Wide Fallback Timezone

Also on this page: a default timezone (used as the fallback whenever an event's own timezone
can't be recognized) — see
[[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference#Basics|Event Configuration Reference]] for where this shows up from an admin's perspective.
