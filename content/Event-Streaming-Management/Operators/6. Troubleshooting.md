# Health Warning Banners

| Banner mentions | Likely cause | What to try |
|---|---|---|
| Incompatible video or audio codec | Your encoder is producing a format the platform can't process reliably | Check your OBS output/encoder settings against your event's usual configuration; ask your system admin if it worked before and stopped working |
| Keyframe interval too long | OBS is set to keyframe less often than the platform needs for clean per-match clipping | Lower the keyframe interval in OBS's output settings (your Video Operator's Guide setup should already set this correctly — recheck it if this warning appears) |
| A YouTube-reported configuration issue | YouTube itself is flagging a problem with the incoming stream | Read the message text — it's passed through from YouTube directly — and check your channel's Live Control Room for the same event |

> [!note] Re-Encoding and Unusual Codecs
> If your source uses a codec other than H.264, the platform can re-encode it when that option is
> enabled for your organization; if it's not, an unsupported source is rejected with a clear error
> naming the codec rather than failing silently. This is a system-wide setting — see
> [[Event-Streaming-Management/System-Administration/4. System Settings Reference|System Settings Reference]] if you need it changed.

# My Event Is Missing

A handful of events (particularly off-season FRC events) aren't shown to every organization
automatically — an admin has to make them visible for your organization first, and a system-wide
setting can hide off-season events entirely. If an event you expect isn't showing up, ask your
Client Admin to check
[[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference#Off-Season FRC Events|Event Configuration Reference]] before assuming something's broken.

# My Upload Is Stuck

See [[Event-Streaming-Management/Operators/5. Clips, Uploads and Signage#Uploads|Clips, Uploads and Signage]] — this is usually a shared quota or operation-mode pause, not something specific to your
event.
