# Logging In

The platform's web dashboard is at [splitter.firstchs.org](https://splitter.firstchs.org). Sign in with the account your Client Admin set up for you — if you don't have one yet, ask your organization's Client Admin to invite you (see [[Event-Streaming-Management/Client-Administration/1. Members and Roles|Members and Roles]]).

# Your Role

What you can see and click depends on the role your Client Admin assigned you: **readonly**, **user**, or **admin**. Most day-of-event tasks (checking event status, running the live controls, reviewing clips) work at the **user** role or above; **readonly** can view everything but can't click any control. A handful of admin-only pages — Stream Keys, integrations, OBS Plugin Devices, and configuring a newly-discovered event — are covered in [[Event-Streaming-Management/Client-Administration/index|Client Administration]] instead of here. See [[Event-Streaming-Management/Client-Administration/1. Members and Roles|Members and Roles]] for the full breakdown of what each role can do.

# Installing the OBS Plugin

Most operators also install the companion OBS Studio plugin, which lets you pick your event directly from a dock inside OBS instead of manually configuring your stream key. It's a Windows-only, signed installer that installs per-user into `%APPDATA%\obs-studio\plugins\chs-obs-plugin\` — no administrator rights needed. OBS loads it automatically the next time it starts; you'll find its dock listed under OBS's **Docks** menu as **CHS Streaming** (check it there if the dock isn't already showing).

An admin on your Client account downloads the installer from the **OBS Plugin** page in the web dashboard (a left-nav item visible to Client Admins) — a **"Download for Windows"** button there always fetches the current release. If you don't have admin access yourself, ask your Client Admin for the installer.

Once it's installed, see [[Event-Streaming-Management/Operators/4. OBS Plugin Guide|OBS Plugin Guide]] to pair it.
