# Logging In

The platform's web dashboard is at [splitter.firstchs.org](https://splitter.firstchs.org). Sign in
with the account your Client Admin set up for you — if you don't have one yet, ask your
organization's Client Admin to invite you (see
[[Event-Streaming-Management/Client-Administration/1. Members and Roles|Members and Roles]]).

# Your Role

What you can see and click depends on the role your Client Admin assigned you: **readonly**,
**user**, or **admin**. Most day-of-event tasks (checking event status, reviewing clips) work at
any role; a few admin-only pages (Stream Keys, integrations, OBS Plugin Devices) are covered in
[[Event-Streaming-Management/Client-Administration/index|Client Administration]] instead of here.
See [[Event-Streaming-Management/Client-Administration/1. Members and Roles|Members and Roles]] for
the full breakdown of what each role can do.

# Installing the OBS Plugin

Most operators also install the companion OBS Studio plugin, which lets you pick your event
directly from a dock inside OBS instead of manually configuring your stream key. It's a
Windows-only, signed installer, and installs per-user (no administrator rights needed) — OBS 30 and
newer will load it automatically once installed.

An admin on your Client account can download the installer from the OBS Plugin page in the web
dashboard (a "Download for Windows" button that always fetches the current release). If you don't
have admin access yourself, ask your Client Admin for the installer.

Once it's installed, see [[Event-Streaming-Management/Operators/4. OBS Plugin Guide|OBS Plugin Guide]] to pair it.
