The OBS plugin adds a dock inside OBS Studio — titled **CHS Streaming** in OBS's Docks menu — that connects to the platform, so you don't have to manually configure OBS's streaming server/key for each event. See [[Event-Streaming-Management/Operators/1. Getting Started#Installing the OBS Plugin|Getting Started]] if you haven't installed it yet.

# Pairing the Plugin

1. In OBS, open the **CHS Streaming** dock (Docks menu, if it isn't already visible). The first time you use it, it shows: *"This device isn't paired yet. Click below, then give the pairing code to your Client Admin."*
2. Click **Pair with CHS Streaming**. The dock briefly shows "Requesting a pairing code…", then a code in the form `XXXX-XXXX` and "Waiting for your Client Admin to enter this code…".
3. Give that code to a Client Admin. On the **OBS Plugin** page in the web dashboard, they click **+ Add Device**, paste your code into the **Pairing Code** field of the **Add Device** dialog, and click **Look Up** — this shows them your machine name, OBS/plugin version, and when the code was requested, so they can confirm it's really your computer before continuing. They can optionally give your device a **Label** (for example "Field 1 Laptop"), then click **Pair Device**.
4. Once paired, the dock shows "Paired!" and moves on to the stream key/event picker below. You only need to do this once per computer — pairing survives OBS restarts.

If nobody claims your code in time, the dock shows *"Pairing code expired. Click the button to get a new one."* — just click **Pair with CHS Streaming** again.

# Not Using the Plugin Manual OBS Setup

You don't have to use the plugin — OBS can be pointed at the platform directly, but the **Stream Keys** page itself is only visible to Client Users and Admins (it doesn't appear in the dashboard nav for a Readonly member). If you're a Client User or Admin: open Stream Keys, copy the **RTMP Streaming Endpoint** URL from the blue box at the top, then click **Copy** on the key you've been assigned to copy the stream key itself straight to your clipboard (no need to click **Reveal** first — Copy sits right next to Reveal). If you're Readonly, ask a Client User or Admin for these two values — there's no other way to get the real key value.

In OBS, go to **Settings > Stream**, set **Service** to **Custom**, paste the copied endpoint into **Server**, and the copied value into **Stream Key**. This is the same information the plugin fills in automatically — using it manually means you'll also want to set your encoder up yourself; see [[#Recommended OBS Output Settings|below]].

# Picking a Stream Key and Event

After pairing, the dock shows a **Stream Key** dropdown and an **Event** dropdown, with a **Select Event** button. Pick the stream key assigned to your setup, then pick today's event from the list under it — only non-archived events on that stream key show up, scoped to your own Client. Selecting an event automatically applies OBS's stream settings and encoder profile (server, key, resolution, bitrate, keyframe interval, and so on) for you — you don't need to enter any of this manually when using the plugin.

# The Live Dock

Once you're paired and an event is selected, the dock becomes your live status panel during the event — it's a server-driven mirror of the control center described in [[Event-Streaming-Management/Operators/3. Running a Live Event|Running a Live Event]], so the same status rows and buttons (Start Push, Stop Push, Go Live, Stop Broadcast, Enable/Disable Signage) appear here too, without leaving OBS. Because the dock's content is sent by the platform, the exact rows and warnings you see can change over time without needing a plugin update.

Two controls only exist in the dock itself:

- **Change Event** — lets you pick a different event. Disabled while OBS is actively streaming (tooltip: "Stop streaming in OBS before changing events.").
- **Unpair This Device** — removes this computer's pairing. Also disabled while streaming.

# Recommended OBS Output Settings

When you select an event through the plugin, it applies an encoder profile that your system admin manages centrally (System Settings — commonly: 1920x1080, 30 fps, 4500 kbps video / 128 kbps audio, 44100 Hz sample rate, and a 2-second keyframe interval). It picks a hardware encoder (NVENC, Quick Sync, or AMF) if your system admin has configured one for your deployment, and otherwise uses OBS's built-in x264 encoder — x264 is always available and is what most setups actually use. If you're setting OBS up manually (see [[#Not Using the Plugin Manual OBS Setup|above]]), match the same resolution, frame rate, and bitrates in **Settings > Output** (Simple output mode), and set your keyframe interval to 2 seconds — a longer keyframe interval is a common cause of one of the health warnings covered in [[Event-Streaming-Management/Operators/6. Troubleshooting|Troubleshooting]].

# Plugin Updates

The plugin checks for a newer version and will let you know one is available, but it does not install updates automatically. When notified, get the latest installer the same way you got the first one and reinstall.
