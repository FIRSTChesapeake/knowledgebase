The OBS plugin is a dock inside OBS Studio that connects to the platform, so you don't have to
manually configure OBS's streaming server/key for each event. See
[[Event-Streaming-Management/Operators/1. Getting Started#Installing the OBS Plugin|Getting Started]] if you haven't installed it yet.

# Pairing the Plugin

1. In OBS, open the plugin's dock and click **Pair with CHS Streaming**.
2. The dock shows a short pairing code.
3. Give that code to an admin on your Client account — they claim it from the OBS Plugin page in
   the web dashboard (see
   [[Event-Streaming-Management/Client-Administration/5. OBS Plugin Devices|OBS Plugin Devices]]).
4. Once claimed, the dock is paired and ready to use. You only need to do this once per computer.

# Picking a Stream Key and Event

In the dock, select the stream key assigned to your setup, then select today's event from the list
under it. Selecting an event automatically points OBS's stream output (server, key, and encoder
profile) at the platform — you don't need to enter this manually in OBS's own stream settings.

# The Live Dock

Once you're paired and an event is selected, the dock becomes your live status panel during the
event. What it shows is sent by the platform itself, so the exact rows, controls, and warnings you
see can change over time without needing a plugin update — treat the dock as a live mirror of the
event's status panel described in
[[Event-Streaming-Management/Operators/3. Running a Live Event|Running a Live Event]], available
without leaving OBS.

# Plugin Updates

The plugin checks for a newer version and will let you know one is available, but it does not
install updates automatically. When notified, get the latest installer the same way you got the
first one and reinstall.
