# Discovered vs Configured Events

The platform automatically discovers upcoming events from the *FIRST* Events APIs, so a new event
usually already exists on the Events page before anyone touches it — but a **discovered** event
only has a name and needs a stream key added before it can do anything. An event becomes
**configured** once someone fills in the rest of its setup.

> [!note] Off-Season and Some Out-of-Territory Events May Not Appear
> If an event you expect to see is missing, it may not be visible to your organization yet — see
> [[Event-Streaming-Management/Operators/6. Troubleshooting#My Event Is Missing|Troubleshooting]].

# Finding Your Event

On the Events page, filter by program and season to narrow the list down; there's also a
hide-past-events toggle for finding what's coming up. Opening an event gives you a live stream
preview and, once it has run, quick access to its metrics.

> [!note] The Season List Includes Next Year
> The season filter always offers the upcoming season in addition to the current and two prior
> ones, since some events are scheduled and published before the calendar rolls over. It doesn't
> switch itself — you (or your Client Admin) pick the season you need.

# Configuring an Event

Open an event and go to its configuration page to fill in:

- **Basics** — event name, timezone, the stream key it will receive video on, which YouTube
  channel clips upload to, and an optional pre-roll video.
- **Blue Alliance credentials** (FRC events only) — needed so match results and video links get
  posted back to The Blue Alliance.
- **Livestream** — whether and how this event restreams to a full YouTube broadcast (see
  [[Event-Streaming-Management/Operators/3. Running a Live Event|Running a Live Event]]), which
  channel it broadcasts to, a thumbnail, and which days it's scheduled to run.
- **Signage** — which event signs (if any) should show this event's stream or queue information
  (see [[Event-Streaming-Management/Operators/5. Clips, Uploads and Signage#Signage|Clips, Uploads and Signage]]).

Your Client Admin sets organization-wide conventions for these fields — see
[[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference|Event Configuration Reference]] if you need the meaning of a specific field spelled out in more detail.
