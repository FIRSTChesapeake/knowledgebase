# The Events Page

Open **Events** in the left nav. Across the top are four filters: a **Season** dropdown, a **Program** dropdown (All / FRC / FTC), a **Hide past events** checkbox, and a **Show unconfigured** checkbox (it shows a count in parentheses). The table below lists: Code, Event Name, Dates, Stream Key, Phase, Status, Clips, and an Actions column.

> [!note] The Season List Includes Next Year
> The season filter always offers the upcoming season in addition to the current and two prior ones, since some events are scheduled and published before the calendar rolls over. It doesn't switch itself — you (or your Client Admin) pick the season you need.

# Discovered vs Configured Events

The platform automatically discovers upcoming events from the *FIRST* Events APIs, so a new event usually already exists on the Events page before anyone touches it. A **discovered** event only has a name and needs a stream key added before it can do anything — the Events page shows it dimmed and greyed-out (not clickable) with a blue **Configure** button instead of a link, and discovered events are hidden by default behind the **Show unconfigured** checkbox. An event becomes **configured** once a Client Admin fills in the rest of its setup — after that its row lights up, becomes clickable, and shows a normal status badge.

> [!note] Off-Season and Some Out-of-Territory Events May Not Appear
> If an event you expect to see is missing, it may not be visible to your organization yet — see
> [[Event-Streaming-Management/Operators/6. Troubleshooting#My Event Is Missing|Troubleshooting]].

# Finding Your Event

Filter by program and season to narrow the list down, and turn on **Hide past events** to see what's coming up. Status badges you'll see in the Status column: **SCHEDULED**, **🔴 LIVE**, **In Progress**, **COMPLETED**, and **ERROR**. A live event also shows a running elapsed-time counter next to its status badge, and, if it's restreaming, a **▶ YT Live** badge next to its name. Clicking a live event's status cell (instead of its name) opens a metrics popup instead of navigating into the event.

# Live Status at a Glance

Opening a configured event takes you to its control center — see [[Event-Streaming-Management/Operators/3. Running a Live Event|Running a Live Event]] for what's there. If your role allows it and stream previews are enabled for your organization, a live event's row also has a **▶ Preview** button you can use without opening the full control center.

# Configuring an Event

Configuring a newly-discovered event (clicking **Configure**) is a Client Admin action — if you're not a Client Admin yourself, ask one to do this before the event needs to go live. Configuring assigns the event's stream key and fills in:

- **Basics** — event name, timezone, the stream key it will receive video on, which YouTube channel clips upload to, and an optional pre-roll video.
- **Blue Alliance credentials** (FRC events only) — needed so match results and video links get posted back to The Blue Alliance.
- **Livestream** — whether and how this event restreams to a full YouTube broadcast (see [[Event-Streaming-Management/Operators/3. Running a Live Event|Running a Live Event]]), which channel it broadcasts to, a thumbnail, and which days it's scheduled to run.
- **Signage** — which event signs (if any) should show this event's stream or queue information (see [[Event-Streaming-Management/Operators/5. Clips, Uploads and Signage#Signage|Clips, Uploads and Signage]]).

For the exact meaning, allowed values, and defaults of every field on this page, see [[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference|Event Configuration Reference]].
