# Downloading the Plugin

The **OBS Plugin** page has a **Download for Windows** button that always fetches the current
release — send this link to your operators, or download it yourself and pass along the installer.
Under the button, the page shows either the latest version number, "Checking for the latest
release…", or (if the button is greyed out and disabled) an error message explaining why no release
is currently available — that's a system-admin-side release issue, not something to fix from this
page.

# Claiming a Pairing Code

When an operator opens the CHS Streaming dock in OBS, it shows them a short pairing code (see
[[Event-Streaming-Management/Operators/4. OBS Plugin Guide|OBS Plugin Guide]]). To claim it:

1. Click **+ Add Device**.
2. Enter the code into **Pairing Code** (format like `ABCD-EFGH`) and click **Look Up**.
3. Before pairing, review the identifying details the lookup shows you — Machine, Platform, OBS
   Version, Plugin Version, Requesting IP, Requested (time), and Code Expires — so you know it's the
   device you actually expect, not someone else's.
4. Optionally give it a **Label** (e.g. "Field 1 Laptop") — this is what shows in the devices table
   and to the operator in the dock; leave it blank and it just shows as "OBS Plugin."
5. Click **Pair Device** (disabled until you've looked up a valid code).

Pairing codes expire — if a lookup fails because the code expired, have the operator reopen the dock
for a new one.

# The Devices Table

Each paired device shows: **Label**, **Platform**, **Version** (plugin version, or "—" if unknown),
**Paired** (when it was claimed), **Last Seen** (last heartbeat, or "Never"), **Token Expires**, and
**Status** (Active/Revoked). There's no manual "refresh" action for Last Seen — it updates on its own
as the device checks in. There's also no way to rename a device after pairing; if you need a
different label, revoke it and pair it again with the label you want.

# Revoking a Device

Click **Revoke** on an active device's row. The confirmation reads exactly:

> Revoke "{label}"?
>
> Its token will stop working immediately -- the operator will need to pair it again.

A revoked device can't be silently reactivated — the operator has to pair it again from scratch
(a fresh pairing code from the OBS dock) to get a new device entry. Do this for any computer that's
retired, lost, or no longer trusted.
