# Downloading the Plugin

The OBS Plugin page includes a **Download for Windows** button that always fetches the current
release — send this to your operators, or download it yourself and pass along the installer.
The button can be turned off platform-wide by a system admin (see
[[Event-Streaming-Management/System-Administration/4. System Settings Reference|System Settings Reference]]); if it's greyed out with a message that no release is currently available, that's a
system admin setting or release issue, not something to fix from this page.

# Claiming a Pairing Code

When an operator pairs the plugin in OBS, it shows them a short pairing code (see
[[Event-Streaming-Management/Operators/4. OBS Plugin Guide|OBS Plugin Guide]]). Enter that code on
the OBS Plugin page to claim the device under your Client. Once claimed, the device can pull the
list of stream keys and events it's allowed to use.

# Revoking a Device

If a computer is retired, lost, or no longer trusted, revoke its pairing from the OBS Plugin page.
The operator will need to pair again from a fresh install to reconnect.
