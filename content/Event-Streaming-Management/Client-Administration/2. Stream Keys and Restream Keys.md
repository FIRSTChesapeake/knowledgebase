# Stream Keys

A stream key is the credential your OBS setup (directly, or through the OBS plugin) uses to send
video to the platform for a given event. Each stream key is created and managed from the Stream
Keys page (admin only).

# Restream Keys

A restream key is used for the YouTube-restreaming path, separate from the stream key used for
ingest. Manage these from the Restream Keys page (admin only).

> [!warning] Treat Keys Like Passwords
> Anyone with a stream key can send video into your Client's account, and anyone with a restream
> key can push to your restream target. Only share a key with the operator or system that needs it,
> and rotate a key if you think it's been exposed.

# Managing Keys

Creating and rotating keys is done from their respective admin pages. Exact field labels can vary
slightly as the platform evolves — if what you see on screen doesn't match what you expect, the
underlying concepts above still apply.
