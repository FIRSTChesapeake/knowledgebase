# YouTube

Link a YouTube channel from the YouTube page (admin only) via Google OAuth — this is the channel
clips upload to and, if configured, broadcasts restream to. You can link more than one channel if
your Client publishes to more than one destination; events choose their upload/broadcast channel
individually (see
[[Event-Streaming-Management/Client-Administration/6. Event Configuration Reference|Event Configuration Reference]]).

> [!important] If a Channel Shows "Needs Re-Authentication"
> YouTube channel links can expire or be revoked on YouTube's side. If a channel is flagged as
> needing re-authentication, uploads and restreams for events using it will fail until an admin
> re-links it from the YouTube page.

# Slack

Link a Slack workspace from the Slack page (admin only) via Slack OAuth to receive event
notifications there.
